# ساتکو (SATCO) — راهنمای اجرا

1. Node.js نسخهٔ ۲۰ یا بالاتر را نصب کنید.
2. پوشه را در VS Code باز کنید و در Terminal بزنید: `npm install --legacy-peer-deps`
3. فایل `.env.example` را کپی کنید و اسم کپی را `.env.local` بگذارید. `ADMIN_PASSWORD` را به یک رمز قوی تغییر دهید. `GEMINI_API_KEY` اختیاری است.
4. اجرا: `npm run dev` و بعد باز کردن `http://localhost:3000`

## ورود آزمایشی
- کد تأیید همیشه `12345` است.
- مدیر کل فقط با شمارهٔ `09120000000` وارد می‌شود (نقش «مدیر کل» با شمارهٔ دیگر دیگر ممکن نیست).

## صفحه‌های اضافه‌شده
- `/panel` پنل کارخانه و شرکت: موجودی (آپلود اکسل)، درخواست‌ها، رزرو تبلیغات، کاتالوگ PDF (چاپ)
- `/admin` مدیریت کل: تأیید کارخانه، رزروها، تعرفه، گزارش، کلید هوش مصنوعی هر کارخانه
- `/visualizer` شبیه‌ساز کاشی‌کاری

## کلید هوش مصنوعی هر کارخانه
در `/admin` تب «هوش مصنوعی»: رمز مدیر را بزنید، کلید Gemini هر کارخانه را ذخیره کنید و «کد دسترسی» ساخته‌شده را به همان کارخانه بدهید. کلیدها فقط در `.data/ai-keys.json` روی سرور می‌مانند.

## هنوز واقعی نیست
شاهکار، درگاه پرداخت، پیامک و پایگاه داده. اطلاعات فعلاً در مرورگر ذخیره می‌شود.
